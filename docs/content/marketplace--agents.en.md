# AI Agent Capacity

Reasoning, planning and exception handling as a bounded capability.

## Contract overview

- Input: Goal + context
- Output: Decision plan / delegated tasks
- Validation: Permissions and escalation boundary

## Scope

An Agent can decide which step is next. It must not independently publish, spend or invent missing approvals.

## Example

Use an Agent to adapt a campaign plan when the brief changes. Delegate rendering to a Routine.
