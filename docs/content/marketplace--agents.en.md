# An agent should own a decision, not every click.

Agents are useful when the path changes. They should reason about intent, delegate bounded work, and stop at the moments only a person can authorize.

## MARKETPLACE / AGENTS

**Positioning and availability:** Agent roles are a design concept, not a catalog of live installable workers.

## What goes wrong when an agent is told to do everything?

A campaign request arrives with a new audience and an outdated source link. A general-purpose agent can write a plan, but the production pipeline needs specific inputs; publishing needs authority; and a failed upload requires evidence before another attempt. Without separate roles, one ambiguous instruction becomes a chain of unchecked assumptions.

**Differentiation:** The useful split is judgment versus execution.

## One intent, deliberately different responsibilities

### 1. Interpret the goal

An agent checks the brief, identifies missing context and proposes a plan.

### 2. Delegate bounded tasks

Each selected Capacity has expected inputs, outputs and permissions.

### 3. Escalate consequential choices

An authorized human reviews claims, audience targeting and external publication.

### 4. Reconcile uncertain outcomes

The agent asks for evidence rather than resubmitting blindly.

## Illustrative case: a product message changes after the first draft.

The marketing lead discovers a new legal review requirement. Rather than regenerating and publishing everything, a coordinating agent can identify the affected claims, route revision tasks to the content and visual stages, and request approval for the final packet. Stable exports remain Routine work. This is an architectural scenario, not a claim that a packaged agent can do this today.

## Questions to ask before introducing an agent

### What judgment does it contribute?

If every rule and branch is predetermined, a Routine may be a better starting point.

### What can it change?

Limit credentials, data access and external actions to declared permissions.

### Where does it stop?

Name the reviewer for public claims, customer communication and consequential transactions.
