# Memory connects decisions to their evidence.

A result is only reusable when the system knows what happened and what remains unresolved.

## Responsibility

1. Project / job identity
2. Artifacts + decisions
3. Receipts + status

## Example

When a publish attempt is UNKNOWN, Memory must retain the attempt and evidence instead of silently calling it failed.
