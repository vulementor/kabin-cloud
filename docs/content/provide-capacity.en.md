# Have a useful tool? Let other solutions use it.

Bring your skill, plugin, SDK, toolkit or API into the Capacity ecosystem. Start with a clear contract, reliable tests and an honest deployment offer.

## What to prepare before submitting

- **01 / The capability:** Repository or service URL, supported task, ownership and license.
- **02 / Its contract:** Inputs, outputs, dependencies, runtime and permissions.
- **03 / Proof it works:** Example input/output, tests, failure limits and resource needs.
- **04 / Deployment & terms:** Where it can run, expected cost and availability when onboarding opens.

## Example and usage

Example: a toolkit that extracts timestamps for scene changes in MP4. It can be used by many video solutions after independent evaluation. It must not claim to render video or access user accounts without permission.
