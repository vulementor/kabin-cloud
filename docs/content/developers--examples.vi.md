# Học qua hợp đồng nhỏ, kiểm chứng được.

Ví dụ nên cho thấy một Capacity làm gì, không giả làm workflow hoàn chỉnh đã tích hợp.

## Contract requirements

1. Nhận diện cảnh
2. Trích xuất tài liệu
3. Adapter dịch vụ có kiểu

## Example

Bắt đầu MP4 → timestamps; tài liệu → trường dữ liệu; API → response có giới hạn. Đây là ví dụ minh họa.
