# Start building your first Capacity.

A Capacity begins with one bounded operation, a contract and an example that can be checked.

## Contract requirements

1. Pick one task
2. Name an input and a result
3. Define a repeatable test

## Example

Example: accept an MP4, return scene timestamps. Do not claim a renderer or uploader is included.
