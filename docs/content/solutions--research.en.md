# Research output needs traceable sources, not just a confident summary.

A research solution discovers, evaluates and cites information before recommending an action.

## Execution flow

1. Research question
2. Sources + dates + extraction
3. Evidence-backed synthesis
4. Reviewer decision

## Solution steps

### Set the scope

Define topic, date window, trusted sources and required decision.

### Collect and compare

Fetch authorized sources, record dates and flag disagreement.

### Deliver an inspectable brief

Cite what changed, uncertainty and suggested next actions.

## Outcome example

Example: monitor a transport infrastructure project and report only genuinely new updates with citations, avoiding recycled news.
