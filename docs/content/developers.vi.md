# Hệ sinh thái Developer

Định hướng để nhà phát triển định nghĩa, tích hợp và chia sẻ năng lực thực thi.

## Định vị
Khái niệm kỹ thuật và hướng tích hợp cho nhà phát triển, chưa phải API đã phát hành.

## Các điểm nội dung
### 1. Hợp đồng trước
Định nghĩa rõ đơn vị thực thi.

### 2. Độc lập runtime
Hướng tới hỗ trợ nhiều công cụ và dịch vụ.

### 3. Kiểm chứng thay đổi
Xây ranh giới kiểm thử trước khi phát hành.
