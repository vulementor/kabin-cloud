## Contract requirements

1. Mục tiêu phiên bản
2. Ảnh hưởng tương thích
3. Bằng chứng mỗi release

## Example

Nếu bộ nhận diện cảnh đổi timestamp từ giây sang mili giây, phải báo breaking change và test lại recipe.
