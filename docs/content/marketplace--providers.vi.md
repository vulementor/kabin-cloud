# Dành cho Capacity Provider

Đóng góp năng lực có hợp đồng để Builder có thể thẩm định.

## Contract overview

- Input: Skill / toolkit / API
- Output: Ứng viên Capacity + offer
- Validation: License, sandbox, quyền

## Scope

Provider cung cấp đơn vị thực thi, không phải toàn bộ kết quả cho khách hoặc quyền production tự động.

## Example

Developer đóng góp bộ nhận diện cảnh MP4; Builder ghép với Capacity render video.
