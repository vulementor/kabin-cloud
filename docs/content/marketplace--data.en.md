# Data & Research Capacity

Transform permitted sources into inspectable structured information.

## Contract overview

- Input: Approved sources + question
- Output: Structured extraction / report
- Validation: Provenance, date, ambiguity

## Scope

The value is not a confident paragraph; it is a result a reviewer can verify from cited sources.

## Example

A market intelligence solution can compare dated government notices and flag what's genuinely new.
