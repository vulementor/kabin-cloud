# BytePlus AI → Kabin V5 design learning

Reference reviewed Oct 11, 2026: https://ai.byteplus.com/en

## Grounded observations

- BytePlus AI uses a cinematic near-black hero, a compact top navigation, strong product-oriented typographic hierarchy, bright animated visual backdrops, and rounded media/product previews.
- Its content progression is: immersive discovery → model showcase → AI-native products → editorial media impact → natural-language closing prompt → rich footer.
- Cards display specific input/output metadata, actions and concrete capability previews rather than only generic promises.
- The closing conversational entry makes the visitor's intended job the next action.

## Kabin V5 translation, without copying BytePlus

| BytePlus pattern | Kabin product-native visual response |
| --- | --- |
| Immersive cinematic hero / media stage | Kabin Core orchestration canvas: Intent, Solution, Capacity, verified Outcome |
| Model cards with I/O metadata | Category-based Capability Marketplace cards with task/input/output and honest 'concept' status |
| AI-native products showcase | Three-sided participation: End User, Solution Builder, Capacity Provider |
| Connected product UI frames | Solution recipe workbench visualizing media, voice, render, human review |
| Case-study storytelling | Illustrative solution switcher (media, research, browser), not fabricated customers |
| Conversational CTA | Local interactive intent → plan preview, explicitly no AI execution |
| Rich footer and top navigation | One consistent six-link header plus visible Provider CTA; company contact |

## Design system

- Kabin's own midnight-indigo visual identity with pale mint/blue/celestial-purple gradients, not BytePlus logos, names, model artwork or pricing.
- Hero is a live CSS orbital canvas; section-specific SVG/CSS visualizations and functional cards are HTML/CSS/JS, not screenshot wallpapers.
- Large typographic headlines, concise explanatory copy, wide product demos, contrast between dark cinematic surfaces and light product shelves.
- English at `/v5/`, Vietnamese at `/v5/vi/`, matching route paths and consistent navigation.
- Reduced-motion support, focus styling, keyboard tab switcher, responsive design down to 320px.

## Non-goals and truthfulness

- No BytePlus source code, trademarks, product screenshots or proprietary imagery are reproduced.
- Kabin Capability Fabric/Memory/Agentic/Routine/ExecutionRecipe are shown as product architecture, not falsely claimed as publicly deployed commerce.
- Any UI implying search, AI plan, capacity listing or provider onboarding is explicitly identified as a concept or email proposal, not a live connected backend.
